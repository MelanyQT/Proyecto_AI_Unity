# Proyecto_AI_Unity
# Proyecto de Modelos de Inteligencia Artificial en Unity

Este repositorio contiene los **scripts, resultados y documentación** asociados al proyecto de implementación y análisis de modelos de inteligencia artificial dentro del entorno **Unity 2022.3 LTS**, desarrollado por **Melany Lizeth Quiceno Triana**.

El propósito de este proyecto fue **comparar tres enfoques de inteligencia artificial aplicados a NPCs (personajes no jugables)**, evaluando su desempeño en adaptabilidad, latencia y satisfacción del jugador.
